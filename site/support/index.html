Support

PKPaneサポート

利用方法や不具合については、以下の情報をご確認のうえお問い合わせください。

動作環境

  • macOS 15以降
  • Apple Silicon搭載Mac

よくある質問

ローカルフォルダを開くには？

サイドバーの「フォルダを追加」からフォルダを選択してください。PKPaneは選択したフォルダへのアクセス許可を保存し、次回起動時に復元します。保護された場所はmacOS側の許可が別途必要になる場合があります。

NAS、SFTP、FTP/FTPSへ接続するには？

接続画面からSMB、SFTP、FTPの接続情報を入力します。SFTPの初回接続では、接続先が正しいことを確認するためホスト鍵を表示します。FTPは証明書を検証する明示的FTPSが既定です。平文FTPを選ぶと資格情報と通信内容が暗号化されない警告を表示します。

対応しているアーカイブ形式は？

ZIPと7zは作成・展開できます。ZIP、7z、tar、tar.gz、tar.bz2、tar.xz、gz、bz2、xz、RARはアプリ内で閲覧・展開できます。パスワード付き7zと、7z作成時の空フォルダ保持には対応していません。

他のアプリからフォルダを開くとFinderが起動する

他のアプリがmacOSの「Finderで表示」機能を使用している場合、Finderが直接起動します。この動作は呼び出し元アプリとmacOSによるもので、PKPaneへ変更できません。通常の「このアプリケーションで開く」に対応した画面では、フォルダを開く候補としてPKPaneを選択できます。

SFTPやFTP上のフォルダを削除するとどうなる？

SFTPとFTPにはmacOSのゴミ箱がないため、確認後にフォルダの中身を含めて完全に削除します。この操作は元に戻せません。

お問い合わせ

support@pky.jpへメール

English

Support

PKPane requires macOS 15 or later and an Apple silicon Mac. For support, email support@pky.jp with your macOS version, PKPane version, steps to reproduce, and the displayed error message.

Do not send passwords, private keys, personal information, or actual user files.

If another app explicitly uses the macOS “Show in Finder” action, Finder opens directly and cannot be replaced by PKPane.

Use the connection panel for SMB, SFTP, FTP, or explicit FTPS. Explicit FTPS validates the server certificate. Plain FTP displays a warning because credentials and traffic are not encrypted.
