Two-pane file manager for macOS

ローカル、NAS、SFTP、FTPを
一つのワークスペースに。

左右を見比べながら、ファイルの閲覧、転送、整理をすばやく安全に行えるmacOS用ファイルマネージャーです。

macOS 15以降・Apple Silicon対応。Mac App Storeで公開予定。

主な機能

場所が違っても、同じ操作感で。

2ペインとタブ

左右の場所を同時に表示し、タブ、お気に入り、履歴、検索を使って目的のファイルへ移動できます。

NASとリモート接続

ローカルフォルダ、SMBで接続したNAS、SFTP、FTP/FTPSサーバー間の転送を共通のキューで管理します。

比較と整理

フォルダ比較、片方向同期、正規表現を使った一括リネームで、繰り返し作業を減らします。

アーカイブ

ZIPと7zの作成・展開に加え、tar、gzip、bzip2、xz、RARなどをアプリ内で閲覧できます。

Privacy by design

ファイルは、あなたが指定した場所だけへ。

広告、利用状況解析、ユーザー追跡は行いません。ユーザーファイルや個人情報を開発者のサーバーへ送信することもありません。

English

Local files, NAS, SFTP, and FTP in one workspace.

PKPane is a two-pane file manager for macOS. Browse, compare, transfer, and organize files across local folders, mounted SMB shares, SFTP, FTP, and explicit FTPS locations with one consistent workflow.

Designed for macOS 15 or later on Apple silicon. Coming to the Mac App Store.
