# PKPane キーマップ

最終的なキーマップ仕様の作業用正本。Finder互換を基準にし、PKPane固有操作と未実装項目を区別する。

## 実装済み

| 操作 | キー | 状態 | 備考 |
| --- | --- | --- | --- |
| 開く | Command-O | 実装済み | 選択項目を開く |
| 開く | Command-↓ | 実装済み | 選択項目を開く |
| 情報を見る | Command-I | 実装済み | 選択項目の名前・種類・サイズ・変更日・場所を表示 |
| アイコン表示 | Command-1 | 実装済み | 選択・複数選択・ドラッグ＆ドロップを維持する |
| リスト表示 | Command-2 | 実装済み | 既存の列表示へ戻す |
| 表示オプション | Command-J | 実装済み | 表示形式、並べ替え、隠しファイル、リストの列を切り替える |
| 戻る | Command-[ / Command-← | 実装済み | フォルダ履歴 |
| 進む | Command-] / Command-→ | 実装済み | フォルダ履歴 |
| 親フォルダへ移動 | Command-↑ | 実装済み | 現在地の親へ移動 |
| フォルダへ移動 | Shift-Command-G | 実装済み | インクリメンタル候補・Sandbox許可導線付き |
| 移動候補を確定 | Tab | 実装済み | 先頭候補を確定し、その下位候補を表示 |
| 移動候補を選択 | ↑ / ↓ | 実装済み | 候補を選択してReturnまたはTabで確定 |
| 新規フォルダ | Shift-Command-N | 実装済み | 現在のフォルダ内に作成 |
| リネーム | Return | 実装済み | 単一選択時のインライン編集 |
| Quick Look | Space / Command-Y | 実装済み | 選択項目をプレビュー |
| 隠しファイル表示切替 | Shift-Command-. | 実装済み | 表示設定を切替 |
| ゴミ箱へ移動 | Command-Delete | 実装済み | 確認後に移動 |
| 複製 | Command-D | 実装済み | 選択項目を複製 |
| コピー / カット / ペースト | Command-C / X / V | 実装済み | アプリ内ファイル操作 |
| 取り消す | Command-Z | 実装済み | 直前のファイル操作を安全に取り消す |
| すべて選択 | Command-A | 実装済み | 表示中の項目を選択 |
| 検索へ移動 | Command-F | 実装済み | 絞り込み欄へフォーカス |
| 更新 | Command-R | 実装済み | 表示中フォルダを再読込 |
| エイリアス／リンクの元を表示 | Command-R | 実装済み | リンクを単一選択している場合は元を表示し、それ以外では更新 |
| 新しいタブ | Command-T | 実装済み | PKPane固有 |
| タブを閉じる | Command-W | 実装済み | PKPane固有 |
| 1/2ペイン切替 | Command-\\ | 実装済み | PKPane固有 |
| 次/前の項目 | Control-N / P | 実装済み | Emacs互換 |
| 次/前ページ | Control-V / Option-Control-V | 実装済み | Emacs互換 |
| 検索へ移動 / 検索終了 | Control-S / G | 実装済み | Emacs互換 |
| 選択解除 | Escape | 実装済み | 一覧選択を解除 |

## 実装予定

| 操作 | Finderのキー | 前提・方針 |
| --- | --- | --- |
| カラム・ギャラリー表示 | Command-3 / 4 | 初期完成版後の範囲として実装時に対応 |
| 候補をダブルクリックして移動 | Double Click | 単クリックによる下位候補表示を維持したうえで追加 |
| 新規ウインドウ | Command-N | 現在はCommand-Tのタブを標準操作とする。複数ウインドウ対応を行う場合に再検討 |

## 対象外または要判断

| 操作 | Finderのキー | 理由 |
| --- | --- | --- |
| ゴミ箱を空にする | Shift-Command-Delete | PKPaneはゴミ箱全体を管理しないため、実装しない |
| 確認なしでゴミ箱を空にする | Option-Shift-Command-Delete | 同上 |
| 新規Finderウインドウと完全同一の挙動 | Command-N | PKPaneではタブを優先するため要判断 |
